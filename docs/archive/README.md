# docs/archive

这里放**已完成使命**的文档：一次性交接、已被后续文档取代的调研、结论已全部并入
`work-queue.md` 的诊断。

## 归档条件（三条全中才能移进来）

1. **无人引用**——`grep -rl <文件名> docs/ CLAUDE.md README.md` 除自身外无命中。
2. **结论已有承接者**——文中每条"已验证事实"与"待决策问题"都能在 `work-queue.md`、
   仍在服役的设计文档或代码里找到落点；找不到落点的必须先打捞成卡，再归档。
3. **不是唯一证据源**——原始数据链仍能从别处取得（`cache-diagnosis-*.md` 一类的
   证据文档即便结论已落地也**不归档**，它们是排除项的唯一记录）。

## 归档不等于删除

归档只表示"不必再读"，不表示"内容作废"。文件保留在 git 与本目录，
`CLAUDE.md` 索引把它们单列一区并注明不再维护。真要删就直接 `git rm`——
让 git 历史成为唯一副本，而不是留一份没人知道该不该信的文件。
