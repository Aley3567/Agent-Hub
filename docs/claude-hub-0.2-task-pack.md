# 0.2 任务包：Standalone 安全快速启动

## 交付目标

没有 CC Switch 时，用户可以创建不含明文 Key 的 Standalone Profile，并启动隔离 Claude 会话；默认不改全局 Claude 配置。

## 前置条件

- 0.1 Exit Gate 已通过，尤其是命令入口、错误语义和 Store DTO 已稳定。
- 明确系统凭证库在目标平台上的支持范围；没有凭证库时必须 fail-closed，不能偷偷写明文文件。
- 不把旧 PR #83、#84、#85、#86、#87 直接合入当前基线。

## 任务卡

### 0.2-A Standalone Profile 元数据存储（#12）

- 目标：原子创建、读取、更新 Profile 元数据；元数据不含 Key。
- 依赖：0.1-B、0.1-A。
- Red：并发写入、进程中断或权限错误会留下半文件、覆盖新版本或泄漏权限。
- Green：使用明确的原子提交和权限合同；损坏记录可诊断且不会被当成有效 Profile。
- 验收：中断模拟、旧版本 schema、并发读写、权限检查、目录持久化说明。
- 不做：凭证值落盘、跨平台强保证的未经验证声明。

### 0.2-B 系统凭证库与 fail-closed（#13）

- 目标：通过系统凭证库保存和读取 Secret 引用，缺失或不可用时拒绝不安全降级。
- 依赖：0.2-A。
- Red：凭证库不可用时回退到 JSON、环境变量或日志。
- Green：Profile 只保存引用；Key 不出现在 argv、环境、Agent JSON、日志、错误正文。
- 验收：可用、不可用、权限拒绝、重复写入、删除后孤儿引用 fixture；secret guard 通过。
- 不做：凭证迁移、账号池、自动轮换。

### 0.2-C Quick Setup 创建与列表（#14）

- 目标：完成 Standalone Profile 创建、校验、列表和选择。
- 依赖：0.2-A、0.2-B。
- Red：部分失败留下不可用 Profile，或者列表将私密值当显示字段。
- Green：创建是可回滚的；列表只显示脱敏引用、能力和状态。
- 验收：重复名称、非法 URL、缺失凭证、取消、中断和恢复测试。
- 不做：直接写 Claude live config。

### 0.2-D Profile 删除、恢复与孤儿凭证（#15）

- 目标：删除 Profile 时保留可审计关系，发现孤儿凭证并给出动作。
- 依赖：0.2-C。
- Red：删除元数据后凭证无主，或恢复时把旧 Key/旧临时文件重新带入会话。
- Green：删除、恢复和孤儿检查有明确所有权；恢复只重建当前版本描述符。
- 验收：删除中断、恢复冲突、孤儿凭证、旧 schema fixture。
- 不做：自动删除用户凭证。

### 0.2-E 短时单次启动描述符（#16）

- 目标：生成最小、短时、单次使用的启动描述符。
- 依赖：0.2-B、0.2-C。
- Red：描述符包含 Key、可长期复用，或被错误进程重复消费。
- Green：描述符只含脱敏引用和必要能力；有过期、消费和失败语义。
- 验收：过期、重复消费、异常退出、错误日志脱敏测试。
- 不做：持久化 token、后台守护进程。

### 0.2-F 隔离 Claude settings（#17）

- 目标：为一次会话生成临时 settings，并在结束后回收。
- 依赖：0.2-E。
- Red：复用用户全局 settings、跨会话污染、临时文件权限过宽。
- Green：settings 只作用于本次会话；权限、清理和异常退出行为可观察。
- 验收：正常退出、强杀、父进程退出、并发会话和权限测试。
- 不做：修改全局默认。

### 0.2-G 跨平台隔离启动（#18）

- 目标：从 `claude-hub`/`claude1` 启动隔离 Claude 会话并保留可诊断结果。
- 依赖：0.2-E、0.2-F。
- Red：启动失败被伪装成成功，或 resume/compact/subagent 路径丢失隔离设置。
- Green：启动、失败、退出和清理状态可区分；外部运行态未验证时明确标注。
- 验收：fake Claude、至少一个真实目标平台 smoke test；其余平台记录缺口。
- 不做：自动 Provider 切换、全局配置写入。

## 0.2 Exit Gate

- Standalone Profile 元数据与凭证引用分离。
- 没有系统凭证库时不会不安全降级。
- 默认启动隔离会话，不修改全局 Claude live config。
- 临时 settings 和启动描述符具备过期、清理和异常退出证据。
- 真实平台未验证的部分必须写“代码完成，运行态未验证”。
